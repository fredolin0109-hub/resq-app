# ResQLink AI Digital Twin Command Center

## 1. Overview
The **Digital Twin Command Center** provides a live spatial, hydrodynamic, and infrastructure replica of disaster zones across Tamil Nadu.

---

## 2. Integrated Modules
1. **Disaster Heatmaps & Spatial Layers (`/rescue/digital-twin/heatmap`)**:
   - Flood depth contours, wind vector velocity, fire spread zones, and population risk density.
2. **Infrastructure Health Monitoring (`/rescue/digital-twin/infrastructure`)**:
   - Live telemetry on bridges, culverts, electrical substations, hospital power backups, and cellular towers.
3. **Disaster Simulation Panel (`/rescue/digital-twin/simulations`)**:
   - Interactive sandboxing of hypothetical scenarios (e.g. +200mm rainfall, dam sluice discharge) to project inundation 12-48 hours into the future.
4. **Disaster Timeline Chronology (`/rescue/digital-twin/timeline`)**:
   - Real-time event sequence playback and forecast visualization.
