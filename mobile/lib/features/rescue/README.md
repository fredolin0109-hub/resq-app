# Rescue Module

## Overview
The Rescue module provides dedicated disaster management, tactical coordination, field response operations, team dispatch, and real-time victim rescue tracking for the ResQLink AI platform.

## Architecture & Layers
- **data/**: Data sources (local/remote), DTO models, and repository implementations.
- **domain/**: Core business entities, repository interfaces, use cases, and domain providers.
- **presentation/**: UI screens, module-specific widgets, controllers, and state management.
- **services/**: Specialized rescue hardware/sensor integrations and background operations.
- **utils/**: Helpers, formatters, and rescue-specific utilities.
